# Gate 3: учебный AI-ассистент банковской поддержки

Прототип для ДЗ № 3. Посетитель задаёт вопрос, а приложение выбирает один из трёх маршрутов: ответ из вымышленной проверенной статьи, уточнение личного случая или демонстрация подготовки обращения сотруднику. Английский классификатор обучен на [Banking77](https://huggingface.co/datasets/PolyAI/banking77); для русского языка есть небольшой классификатор на синтетических примерах. При настройке GigaChat удалённая модель классифицирует вопросы и создаёт уточнения или черновики. Ответы об условиях берутся только из учебной базы знаний.

**Состояние на 25 октября 2026:** функция `banking77-demo` в отдельной папке Yandex Cloud пока приватная. Локальные сценарии ранее проверены. Доступность OAuth и API GigaChat из Cloud Shell подтверждена с проверкой TLS, но ключа авторизации ещё нет, поэтому живой вызов модели и публичный адрес не подтверждены. VPS финансового бота не используется.

## Сценарии демонстрации

| Вопрос | Ожидаемое поведение |
| --- | --- |
| `Сколько идёт доставка карты?` | Autopilot: учебная статья KB-001 |
| `Где мой платёж?` | Уточнение типа операции; реального статуса нет |
| `Какой статус у моей карты?` | Уточнение: доставка или возможность пользоваться картой |
| `Какая у меня комиссия?` | Уточнение операции и тарифа; цифры не выдумываются |
| `Я не узнаю это списание` | Copilot: контекст и черновик для сотрудника |
| `Демо: покажи тестовый статус карты` | Явно помеченная синтетическая запись |

## Как работает маршрут

1. Правила сразу направляют очевидное мошенничество, спорные списания и потерю карты в Copilot.
2. При наличии `GIGACHAT_AUTH_KEY` GigaChat-2-Max получает вопрос, короткую историю и названия 77 тем Banking77. Он возвращает структурированное решение. Ключ хранится только в переменной окружения функции; в Git и переписку его добавлять нельзя. Если модель недоступна, приложение использует локальные учебные классификаторы.
3. Автоматический ответ возможен лишь для разрешённых тем с подходящей статьёй в `knowledge_base.json`. GigaChat не является источником тарифов, сроков или личных статусов.
4. Для личного случая без доступа к банковским данным приложение уточняет запрос. Команда `Демо: покажи тестовый статус карты` отдельно показывает синтетический статус.
5. Copilot показывает историю, отсутствие CRM и редактируемый черновик. Настоящей очереди сотрудников и передачи обращения нет.

## Размещение в Yandex Cloud Functions

Точка входа: `yandex_function.handler`. ZIP должен содержать исходники, `data/categories.json`, файлы моделей, шаблон, базу знаний и официальный корневой сертификат Минцифры в `data/russian_trusted_root_ca_pem.crt`. Сертификат берётся с [официального адреса, указанного в документации GigaChat](https://developers.sber.ru/docs/ru/gigachat/certificates) и используется через `ssl.create_default_context(cafile=...)`; проверка TLS не отключается. Путь можно переопределить переменной `GIGACHAT_CA_BUNDLE`.

Ключ авторизации физлица создаётся в [кабинете GigaChat API](https://developers.sber.ru/docs/ru/gigachat/individuals-quickstart) и записывается в `GIGACHAT_AUTH_KEY` только в настройках Cloud Function. Старый `OPENROUTER_API_KEY` следует убрать из активной версии. Новую версию сначала проверяют приватно: `/api/health`, страницу и русские сценарии `/api/ask`, включая живой ответ GigaChat и безопасное поведение при ошибке API. После успешной проверки функцию открывают для преподавателя по простому HTTPS-адресу и повторяют проверку без авторизации. До этого публичный адрес не считается готовым.

[Документация OAuth](https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/gigachat-api) · [Структурированный вывод](https://developers.sber.ru/docs/ru/gigachat/guides/structured-output) · [Тарифы физлиц](https://developers.sber.ru/docs/ru/gigachat/tariffs/individual-tariffs). Наличие бесплатного лимита и доступность выбранной модели для конкретного аккаунта проверяются в кабинете GigaChat.

## Данные, измерения и ограничения

- Banking77: 10 003 обращения в train, 3 080 в test, 77 тем, английский язык, лицензия CC BY 4.0. Цитирование: Casanueva et al. (2020), [Efficient Intent Detection with Dual Sentence Encoders](https://arxiv.org/abs/2003.04807).
- `knowledge_base.json` содержит вымышленные условия Демо-банка. Banking77 содержит вопросы и темы, но не ответы банка.
- `evaluation_report.json`: английский классификатор на официальном test split, accuracy 0,905, macro F1 0,905. Из 172 автоматических ответов 165 выбрали верную тему; 0 из 480 рискованных вопросов получили автоответ.
- `ru_evaluation_report.json`: русский классификатор на 30 авторских синтетических фразах, accuracy 0,800, macro F1 0,796. Это небольшая учебная проверка.
- Метрики локальных моделей не измеряют качество GigaChat. Нет доступа к картам, платежам, CRM или операторам. История хранится в браузере до обновления страницы. Лимит API — 30 вопросов в час на адрес подключения; это учебное ограничение, а не полноценная защита от злоупотреблений.
