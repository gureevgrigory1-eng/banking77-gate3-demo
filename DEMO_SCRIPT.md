# Сценарий демонстрации на 2–5 минут

Откройте публичный HTTPS-адрес после публикации на Render. Проверка не требует установки или запуска чего-либо на компьютере преподавателя. В `/api/health` поле `remote_enabled` показывает, подключена ли удалённая Qwen. Без ключа работает ограниченный облачный классификатор. Используйте только вымышленные вопросы.

| Время | Действие и комментарий |
| --- | --- |
| 0:00–0:25 | Объясните данные: Banking77 содержит вопросы и темы, а не ответы банка. Условия Демо-банка вымышлены и отмечены в интерфейсе. |
| 0:25–0:55 | Нажмите «Доставка карты». Покажите Autopilot, статью KB-001 и её источник. |
| 0:55–1:25 | Нажмите «Где мой платёж?». Ассистент уточняет тип операции и не утверждает, что видит реальный платёж. |
| 1:25–1:50 | Нажмите «Статус карты». Покажите уточнение. Затем нажмите «Тестовый статус карты» и покажите маркировку синтетической записи. |
| 1:50–2:20 | Нажмите «Комиссия». В базе нет подтверждённой статьи с суммой; ассистент уточняет операцию и тариф. |
| 2:20–2:50 | Нажмите «Спорное списание». Покажите Copilot: историю, отсутствие CRM и редактируемый черновик. Реального оператора в демо нет. |
| 2:50–3:20 | Откройте `evaluation_report.json` и `ru_evaluation_report.json`. Первый отчёт — тест Banking77 на английском, второй — маленькая авторская синтетическая выборка на русском. Они не оценивают Qwen. |
| 3:20–4:00 | Объясните следующий шаг для настоящего пилота: утверждённая база знаний банка и отдельная оценка на реальных русскоязычных обращениях. |
