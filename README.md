# Демо-банк: помощник по продуктам

[Открыть помощника](https://d5dguggs5hklduk1kqbv.g2n58e0c.apigw.yandexcloud.net/)

Помощник отвечает на вопросы о картах, сбережениях, кредите и переводах Демо-банка. Названия продуктов и условия придуманы для этого сервиса и не относятся к действующим банкам. Чат не имеет доступа к счетам и не выполняет операции.

## Как устроен ответ

1. Поиск выбирает до пяти материалов из базы знаний. Сейчас работает поиск по словам и их сочетаниям.
2. GigaChat-2-Max определяет, можно ли ответить, требуется ли уточнение, есть ли личный вопрос или риск, и формулирует ответ по найденным сведениям.
3. Сервер проверяет идентификаторы использованных источников. В интерфейсе можно открыть подробности условий.
4. При неоднозначном вопросе помощник уточняет смысл. Если три уточнения подряд не помогли, он готовит описание для специалиста. Автоматической отправки и подключения сотрудника пока нет.
5. При временном сбое модели помощник сообщает об этом и показывает подходящие сведения из базы.

В базе 32 статьи. Условия продуктов и сроки операций хранятся в `knowledge_base.json`; числовые параметры собраны в `product_catalog.json`. Согласованность проверяется командой `python scripts/check_kb.py`. Вопросы через `/api/ask` принимаются в формате `{"query":"...","history":[{"role":"user|assistant","text":"...","route":"answer|clarify|..."}]}`. Поле `route` нужно только для сообщений помощника, чтобы учитывать последовательность уточнений. `/api/health` показывает состояние сервиса и версию базы.

В каталоге три карты действуют на всей территории России и в Великобритании для оплаты покупок. Покупка обычно подтверждается за несколько секунд и отражается в выписке в течение 3 рабочих дней. Переводы внутри Демо-банка обычно занимают до 1 минуты; переводы по реквизитам и через СБП — до 1 рабочего дня. Условия оплаты в иностранной валюте и возможные комиссии пока не заданы.

## Проверка и запуск

- `PYTHONPATH=. python -m unittest discover -s tests -v` — проверки маршрутизации, источников, уточнений и ответа при сбое.
- `python scripts/check_kb.py` — проверка состава и согласованности базы.
- `python app.py` — местный интерфейс (Python 3.12, зависимости в `requirements.txt`). Без ключа GigaChat сервис отвечает по найденным сведениям.

`evaluation/dev.json` и `evaluation/control.json` содержат прежние наборы вопросов. Результаты в `evaluation_report.json` получены до обновления базы и текста ответов; после размещения новой версии оценку нужно повторить. Эти наборы составлены автором и не заменяют независимую проверку качества.

## Размещение

Публичный адрес обслуживает Yandex API Gateway и закрытую Cloud Function `banking77-demo`. Ключ GigaChat хранится в Yandex Lockbox и передаётся функции как `GIGACHAT_AUTH_KEY`; в репозитории его нет. Проверка TLS использует корневой сертификат, указанный в [документации GigaChat](https://developers.sber.ru/docs/ru/gigachat/certificates).

Обновление репозитория само по себе не обновляет опубликованную Cloud Function: после слияния требуется отдельное размещение версии функции и проверка `/api/health` и `/api/ask`.
